# План боевых тем: Дженифер, Вайолет, Саша

Дата: 2026-09-05

## Контекст и ограничение

Боевая тема каждой героини звучит **почти всё время забега** — во всех обычных
боевых комнатах. Не звучит: в комнатах-боссах, в редких/квестовых комнатах
(`RareRoomConfig`/`RareRoomContent`) и во время ВН-сцен (`VNManager.TryPlayScene`).
Это значит:

- Тема обязана быть **бесшовно зацикленной** (десятки повторов за один забег —
  любой щелчок/пауза на стыке петли будет слышен постоянно и раздражать).
  Один забег — это долгое время в бою; трек будет проигрываться не 2-3 раза, а
  условно 20-50+ раз за сессию.
- Тема обязана **не надоедать** при таком количестве повторов. Значит: никаких
  навязчивых "цепляющих" мелодических хуков на первом плане, умеренная
  вариативность внутри петли, никакой вокальной партии/явного текста.
- Три темы должны быть **легко различимы** (игрок должен на слух понимать, за
  кого сейчас играет), но при этом восприниматься как один саундтрек одной
  игры — общий тональный/темповый язык, как и в `ChestOpen_Jingle.rpp` (120
  BPM, E major) для узнаваемой звуковой идентичности проекта.

## Музыкальный характер по персонажам

Опирается на интро-сцены (`Assets/StreamingAssets/Content/Scenes/*_intro_*.json`)
и класс персонажа.

### Дженифер — воин(-генералист), стартовый персонаж
Спокойная, компетентная, "надёжная". Первая тема, которую слышит игрок —
должна задавать общий тон саундтрека, а не быть самой яркой из трёх.
- **Характер:** уверенный маршевый ритм, без агрессии. Твёрдая опора на бас и
  перкуссию, минимум диссонанса.
- **Инструментарий:** духовые/струнные пэды + чёткая перкуссия, лёгкий
  клавишный/арпеджиатор для движения (перекликается с `Pad_Build`/`Arp_Build` из
  джингла сундука — общий тембровый словарь проекта).
  Клавишный подпад лучше от синтезатора Surge XT, который уже используется в в
  ChestOpen_Jingle — тот же инструментарий, тот же "голос" проекта.
- **Темп:** 120-128 BPM, ровный.

### Вайолет — Плут (Rogue), холодная, опасная, скрытная
Резкая, собранная, минималистичная. Ощущение контроля и угрозы, не хаоса.
- **Характер:** синкопированный, "крадущийся" ритм (смещённые акценты вместо
  ровной доли), больше пространства/пауз в аранжировке, чем у остальных двух —
  напряжение через недосказанность, а не через плотность.
  Минорная тональность (например, C# minor — та же тоника, что E major по
  относительному родству, для тонального родства с общим "домом" саундтрека).
- **Инструментарий:** приглушённые перкуссионные текстуры (шейкеры, закрытый
  хай-хэт), короткие стаккато-струнные уколы, минимум сустейна.
- **Темп:** чуть быстрее — 130-136 BPM, но ощущается собраннее за счёт пауз.

### Саша — Варвар, громкая, азартная, любит хороший бой
Взрывная, "мясная", радость от драки, без злобы — скорее кураж.
- **Характер:** тяжёлая, "топающая" перкуссия на каждую долю, широкий гитарный
  /низкий синтовый риф на переднем плане, короткие ударные акценты-выкрики
  (перкуссионные, не вокальные — избегаем прямого вокала по правилу "не должно
  надоедать/раздражать").
- **Инструментарий:** overdriven bass/synth-риф, большие томы, редкие духовые
  стабы для акцента.
- **Темп:** самый быстрый — 138-145 BPM.

## Структура одной темы (борьба с усталостью слушателя)

Единая схема для всех трёх, чтобы петли были технически однородны:

1. **Петля без интро.** Файл = ровно один цикл, точка входа = точка выхода
   (сэмпл в сэмпл). Никакого отдельного "разгона", как у джингла сундука —
   комбат-тема должна звучать одинаково хорошо при входе В ЛЮБОЙ момент боя,
   не только с начала.
2. **Длина петли: 24-32 такта** (при типичном темпе ~120-145 BPM это ~45-65
   секунд). Короче — приедается быстро; длиннее — тяжелее для бесшовного лупа
   и для последующей правки.
3. **Внутренняя вариация без потери зацикленности:** петля делится на 2 блока
   по 12-16 тактов (A/B) с разной плотностью аранжировки (например, B — без
   ударных, только пэд+бас, для "передышки" уха), но с одинаковым гармоническим
   рисунком, чтобы стык между повторами всей петли оставался бесшовным.
4. **Никакой мелодии на переднем плане, которую хочется напевать.** Ведущий
   голос — ритмический/гармонический, а не melodic hook. Это осознанный выбор
   против "въедается и раздражает" при 30+ повторах за сессию.
5. **(Опционально, отдельная будущая итерация) Динамические слои по интенсивности
   боя** — например, дорожка ударных чуть громче на "тяжёлых" размена (не
   критично для первой версии, но стоит сразу сводить на отдельные стемы
   Perc/Bass/Pad/Lead, чтобы включить это позже без пересведения с нуля).

## Технический план (Reaper)

Для каждой из трёх тем — отдельный `.rpp` в `Audio/Music/`
(например `Audio/Music/CombatTheme_Jennifer.rpp`), по аналогии с
`Audio/SFX/ChestOpen_Jingle.rpp`:

1. Трек-скелет: Pad, Bass, Perc, Lead/Riff — сведены на отдельные дорожки
   (задел под будущие динамические слои, см. п.5 выше).
2. Мастер-бас с лимитером сразу в проекте (см. found-and-fixed баг в джингле:
   мастер-фейдер там оказался случайно продавлен до -31dB — в новых проектах
   сразу проверяю `MASTER_VOLUME` перед первым рендером, чтобы не повторить).
3. Экспорт: один WAV на тему, точка старта/конца ровно на границе такта,
   проверка бесшовности — рендер тема+тема подряд и визуальный/аналитический
   контроль стыка (не должно быть щелчка/скачка амплитуды на границе).
4. Файлы кладутся в `Assets/Audio/Music/CombatTheme_<Character>.wav`,
   `AudioClip.Import Settings`: **Loop = true**, Load Type = Decompress on
   Load (короткий файл, не стриминг).

## Интеграция в код (следующий шаг после звука)

Не часть этой задачи, но чтобы план был actionable:

- Новый `AudioSource` для музыки (категория `AudioCategory.Music`, уже
  заведена в `TaggedAudio`/`AudioSettingsManager` — громкость будет
  регулироваться отдельным слайдером, когда он появится в Настройках).
- Проигрывание/переключение темы по `characterManager.Character.characterId`
  при входе в бой; **пауза музыки** (не остановка — `AudioSource.Pause()`,
  чтобы не терять позицию петли) на входе в комнату босса/редкую комнату и на
  запуск ВН-сцены; **возобновление** на выходе.
- Кроссфейд 0.3-0.5с при паузе/возобновлении, чтобы не было резкого обрыва.
