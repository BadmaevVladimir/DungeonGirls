# Level-Up Card Descriptions & Global Text Outline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two GDD 7.2 UI requirements: (1) level-up option cards must show the skill/upgrade's effect description text, not just its name — the descriptions already exist in the `PassiveSkillData`/`ActiveSkillData` assets (3.9/3.10/3.1), only the UI wiring is missing; (2) all run-screen text (ideally all UI text) needs a stroke/outline for readability over arbitrary backgrounds.

**Architecture:** `LevelUpOption` gains a `Description` property alongside its existing `ToString()` (title). `RunFlowController.LevelUpFlow` renders each card as a title + description (matching the existing two-line pattern already used for item-slot comparison cards in `ItemCompareFlow`). The text outline is a single global USS rule using UI Toolkit's `-unity-text-outline-width`/`-unity-text-outline-color` properties (native support, confirmed available in Unity 6000.5.8f1's UI Toolkit) on the `Label` and `Button` element-type selectors — no per-element class changes needed.

**Tech Stack:** Unity 6000.5.8f1, C#, UI Toolkit (USS).

**Spec:** ГДД Данжнгерлс (рабочая версия), section 7.2. User sync prompt item 12.

## Global Constraints

- Description text must come from existing GDD-authored content (`PassiveSkillData.effectDescription`, `ActiveSkillData.effectDescription`) — do not invent new copy.
- The outline must not be applied only to the level-up window — GDD 7.2 explicitly says "и желательно — во всём UI забега", so this plan applies it project-wide via a type selector rather than a scoped class, covering the hub/buildings/gacha screens too (harmless there, same readability need applies).

- [ ] **Step 1: Add the `Description` property**

```csharp
// Assets/Scripts/Progression/LevelUpOption.cs — add alongside the existing ToString():

// 7.2 [НОВОЕ]: текстовое описание эффекта для карточки левел-апа — берётся из уже существующих
// полей effectDescription (3.9/3.10 — PassiveSkillData; 3.1 — уникальный активный навык персонажа,
// ActiveSkillData). Уникальный пассивный навык персонажа тоже PassiveSkillData (см. CharacterData),
// поэтому UpgradeUniquePassive использует то же поле Skill, что и NewPassiveSkill/UpgradePassiveSkill.
public string Description
{
    get
    {
        switch (Type)
        {
            case LevelUpOptionType.NewPassiveSkill:
            case LevelUpOptionType.UpgradePassiveSkill:
            case LevelUpOptionType.UpgradeUniquePassive:
                return Skill != null ? Skill.effectDescription : string.Empty;

            case LevelUpOptionType.UpgradeUniqueActive:
                return ActiveSkill != null ? ActiveSkill.effectDescription : string.Empty;

            default:
                return string.Empty;
        }
    }
}
```

`UpgradeUniqueActive` currently has no way to reach the character's `ActiveSkillData` (only `LevelUpManager.GenerateLevelUpOptions` has `progress.Character.uniqueActiveSkill` in scope when it constructs the option, and `LevelUpOption` doesn't store it). Add the missing field:

```csharp
// Assets/Scripts/UI/RunFlowController.cs, inside LevelUpFlow(), was:
// foreach (var option in options)
// {
//     var btn = new Button { text = option.ToString() };
//     btn.AddToClassList("choice-card");
//     levelUpCardsContainer.Add(btn);
//     buttons.Add(btn);
// }
// becomes — two-line text (title + description), same pattern ItemCompareFlow already uses for
// slot-choice buttons ("Заменить: {name}\n{stats}"):
foreach (var option in options)
{
    string description = option.Description;
    string cardText = string.IsNullOrEmpty(description) ? option.ToString() : $"{option}\n{description}";
    var btn = new Button { text = cardText };
    btn.AddToClassList("choice-card");
    levelUpCardsContainer.Add(btn);
    buttons.Add(btn);
}
```

(`$"{option}\n{description}"` implicitly calls `option.ToString()` inside the interpolation — unchanged title text, now followed by the description on a new line. `.choice-card` already sets `white-space: normal` and `height: auto`, so multi-line text already renders correctly — confirmed by reading `Assets/UI/GameStyles.uss:258-266` before writing this plan.)

### Task 3: Global text outline/stroke

**Files:**
- Modify: `Assets/UI/GameStyles.uss`

**Interfaces:** None (pure USS, no C# surface).

- [ ] **Step 1: Add the global outline rule**

```css
/* Assets/UI/GameStyles.uss — add near the top of the file, before the first class rule, so more
   specific rules below can still override it per-element if ever needed: */

/* 7.2 [НОВОЕ]: весь текст UI должен иметь обводку/тень для читаемости поверх произвольного фона.
   Type-селекторы (Label, Button) покрывают весь проект разом — хаб/здания/гача/забег — а не
   только окно левел-апа, как явно предпочитает ГДД ("и желательно — во всём UI"). */
Label, Button {
    -unity-text-outline-width: 1px;
    -unity-text-outline-color: rgba(0, 0, 0, 0.75);
}
```
