# opendaw-mcp

MCP-сервер, дающий модели восемь инструментов для сборки и рендера музыкальных аранжировок
через headless-копию движка [openDAW](https://opendaw.studio/), поднятую в Chromium.

## Установка

```bash
npm install
npx playwright install chromium
npm run build
```

`npm run build` собирает статическую страницу-хост (`host/dist/index.html`, движок openDAW
в headless-режиме) и компилирует сам сервер (`dist/index.js`).

Версии пакетов `@opendaw/*` в `package.json` запинены точно. Не меняйте их, чтобы обойти
проблему — если версия мешает, это повод сообщить о блокере, а не тихо подвинуть номер.

## Запуск

```bash
node dist/index.js
```

Сервер говорит по stdio (`StdioServerTransport`) — подключайте его как любой другой MCP-сервер.
Переменная окружения `OPENDAW_OUTPUT_DIR` задаёт, куда писать WAV (по умолчанию `Audio/Music`
относительно текущей директории процесса).

## Инструменты

- **describe_devices** — каталог инструментов и эффектов openDAW: параметры, диапазоны, единицы.
- **build_arrangement** — собрать проект из документа-аранжировки (см. ниже). Заменяет
  предыдущий проект целиком; отказывает до касания браузера, если документ не проходит схему
  или ссылается на неизвестное устройство/параметр.
- **inspect_project** — сводка текущего проекта (`null`, если ничего не собрано).
- **reset_project** — очистить проект без перезапуска браузера.
- **render** — отрендерить микс или стемы в WAV. `loop: true` сворачивает хвост затухания на
  начало лупа; для этого нужен либо явный `range`, либо поле `loop` в документе, и его конец
  обязан совпадать с концом документа (иначе после лупа звучит настоящий материал, а не только
  затухание, и просьба отклоняется с объяснением).
- **import_asset** — импортировать сэмпл (`.wav`/`.mp3`/`.flac`) или soundfont (`.sf2`) с диска.
- **list_assets** — импортированные сэмплы и soundfont с именами для ссылок из документа.
- **export_bundle** — сохранить `.odb` для ручных правок в UI openDAW.

## Пример документа

```json
{
  "name": "Demo",
  "tempo": 120,
  "end": "5.1",
  "loop": {"start": "1.1", "end": "5.1"},
  "patterns": {
    "riff": {"length": "1b", "notes": [{"p": "C3", "at": "1.1", "d": "1/4"}]}
  },
  "tracks": [
    {
      "name": "Lead",
      "instrument": {"device": "Vaporisateur"},
      "stem": "lead",
      "place": [{"pattern": "riff", "at": "1.1", "repeat": 4}]
    }
  ]
}
```

Позиции — вида `такт.доля` или `такт.доля.шестнадцатая` (с единицы, не с нуля). Длительности —
`Nb` (тактов) или `1/N`, `1/N.`, `1/Nt` (доля такта, с точкой или триолью).

## Ограничения

- **Рендер лупа требует `loop.end == end`**. Диапазон рендера в openDAW не обрезает хвост —
  только стартовая позиция делает seek. Если `loop.end` меньше `end`, всё, что за `loop.end`,
  разворачивается как затухание и складывается на начало петли, что даёт артефакт. Сервер отказывает
  с объяснением вместо того, чтобы создать неправильный файл.

- **Путь soundfont не протестирован**. SF2-парсинг, список пресетов и привязка инструмента к soundfont
  проверены только чтением кода — валидной `.sf2` фикстуры не было. Сэмплы, синтезаторы и ударная
  линия Playfield охвачены тестами.

## Устройство

- `src/schema.ts` — валидация документа: форма (zod) плюс перекрёстные проверки (разбор времени
  и высот, ссылочная целостность).
- `src/validate-devices.ts` — проверка устройств и параметров против живого каталога движка.
- `src/expand.ts` — разворачивание паттернов и повторов в плоский список регионов.
- `src/bridge.ts` — мост Node ⇄ headless-страница (статический сервер + Playwright/Chromium).
- `src/loop.ts`, `src/wav.ts`, `src/pcm.ts`, `src/time.ts` — свёртка хвоста лупа, запись WAV,
  декодирование PCM (движок отдаёт каналы как base64), разбор времени.
- `src/server.ts` — сборка восьми инструментов в `McpServer`.
- `src/index.ts` — исполняемый вход (`bin`), поднимает сервер поверх stdio.
